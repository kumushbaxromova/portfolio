css-saytlarga dizayn beradi.

biz html faylimizga css ni 3 xil yo'l bilan berishimiz mumkin.

\

  1. external, ya'ni alohida css fayl ochib, uni html faylimizga ulash

  2. internal, ya'ni head va body o'rtasida style ochib shuning ichiga hamma dizaynlarni berish

  3. inline, ya'ni har bir yozilgan elementning o'ziga still berib ketish.
